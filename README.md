# Talent Track

Talent Track is a resume analysis web application developed using Python and Flask. The project allows users to upload a resume and receive insights such as extracted skills, suitable career roles, missing skills, and interview questions.

## Features

* Resume Upload
* Skill Extraction
* Career Role Suggestions
* Missing Skill Analysis
* Interview Question Generation
* PDF Download Support

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
